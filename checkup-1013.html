1개월 검진 정리

10월 13일 · 녹음 29분을 받아쓴 뒤 정리 · 몸무게 4.3kg · 완전 분유

⚠ 이럴 땐 바로 병원(응급실)

  • 아기가 파랗게 보이거나(입술·얼굴), 잘 못 먹거나, 숨이 이상할 때. 심장 소리 때문에 특히 챙길 것
  • 배꼽에서 진물·피가 계속 나거나, 1주 뒤에도 분홍 살이 그대로 보일 때 → 다시 내원

📅 다음 일정

약 1주 뒤배꼽 상태 확인 (그대로면 한두 번 더 처치)
11월 15일부터2개월 접종 + 심장 소리 다시 듣기

다른 소아과에서 접종하면 이렇게 전하기: “1개월 검진 때 심잡음 비슷한 애매한 소리가 오른쪽에서 들렸고, 2개월에 없어졌는지 확인하기로 했다.”

🩺 오늘 진찰 결과

키·몸무게·머리둘레잘 크고 있음
고관절 · 고환 위치정상
엉덩이 딤플(보조개)괜찮음
설소대오늘 보기엔 특별한 문제 없음. 집에서 한번 관찰해 보기
심장 소리심장 옆(오른쪽)에서 애매한 소리. 잡음이라 하기엔 애매한 정도. 잘 먹고 잘 지내는 아기는 대부분 저절로 없어짐 → 2개월에 재확인
배꼽분홍색 촉촉한 살 = 육아종. 오늘 약으로 처치. 한 번에 안 끝나면 1~2번 더

🫧 배꼽 관리 (나아질 때까지)

  • 뽀송하게가 제일 중요. 통목욕보다 부분 목욕 위주 (물 조금 묻는 건 괜찮음)
  • 진물 보이면 바로 소독솜으로 닦기. 중간중간 들여다보기
  • 처치 직후엔 진물이 조금 나올 수 있음 (정상)

🍼 수유

  • 지금처럼 2시간 반~3시간 간격, 100ml 괜찮음. 억지로 늘리지 말고 아기가 찾는 만큼
  • 대신 3~4일~1주에 한 번 체중 재기. 기준(생후 3개월까지): 하루 약 30g · 1주 약 0.2kg · 한 달 약 1kg
  • 먹고 1시간~1시간 반 만에 또 찾으면 → 먼저 졸린 건지 의심 (하품, 눈꺼풀 무거움, 반응 느려짐, 입 오물오물)
  • 100ml 먹고 쩝쩝대면 조금 더 줘 보기. 더 줘도 계속 쩝쩝대면 양 문제는 아님. 과식하면 많이 게워냄 → 그건 많이 먹은 신호
  • 밤수: 지금은 3~4시간 넘기지 않게 깨워서 먹이기. 2개월쯤부터는 6~7시간 쭉 자면 깨우지 않아도 됨

😴 잠

  • 낮잠은 2시간에서 끊기 (지금부터). 2시간쯤 되면 슬슬 깨우기. 낮잠이 길면 밤낮이 바뀜. 밤잠이 길게 자리 잡으면 낮잠이 길어도 괜찮음
  • 지금 밤잠 최장 3~3.5시간. 정상
  • 깨어 있는 시간: 1개월 ≈ 1시간 → 2개월 ≈ 1시간 20~30분. 몇 분씩 늘어나는 걸 기록해 두면 졸음 타이밍을 놓치지 않음
  • 수면 루틴 (6주부터 권장): 누가 재우든 같은 순서로. 예) 졸음 신호 → 재우는 방으로 → 조명 낮추기 → 백색소음 → 노래 → 같은 말 한마디(“사랑해, 잘 자”). 낮잠에도 똑같이
  • 찡그리며 깨는 건 기질. 잘못 재운 게 아님. 먹고 기분 좋아지면 배고픔이었던 것

🛡 안전 (돌까지)

  • 영아 돌연사 예방이 이 시기 제일 중요. 푹신한 이불·베개를 덮거나 깔지 않기 (질식 위험)
  • 두상 베개는 효과 거의 없음
  • 엎드려 놀기(터미타임)는 지금부터: 엄마·아빠가 보고 있을 때만, 단단한 바닥에서, 팔은 양옆으로 편하게. 고개는 한 번씩 반대로 돌려 주기. 힘들어하면 내려 주기. 두상·목 힘에 좋음

🧴 피부 · 코 · 입

  • 얼굴·몸 붉은 것: 가벼운 신생아 홍반. 더울 때 올라옴 → 시원하게 해 주면 들어감. 태열 전용 크림까진 필요 없음
  • 보습: 얼굴 포함 골고루. 거칠고 비닐처럼 보이는 건조한 곳엔 로션 위에 비판텐 덧바르기
  • 코 그렁그렁: 식염수 방울이든 스프레이든 편한 걸로. 하루 여러 번 써도 됨. 빼내지 않아도 됨. 보존제 없는 제품 추천 (생리식염수 또는 해양심층수 단독 성분)
  • 잇몸: 지금은 습관 들이기로 하루 1~2번, 거즈 손수건·실리콘으로 톡톡 마사지하듯 (박박 닦지 않기)
  • 이가 나면: 불소 1000ppm 치약으로 하루 2번, 부모가 닦아 주기

💩 변 · 방귀 · 딸꾹질

  • 노란색과 녹색이 섞인 변: 괜찮음
  • 방귀 잦은 것: 변이 잘 나오면 문제없음
  • 딸꾹질: 자연스러움. 주로 온도 변화 때문 → 기저귀 젖었는지, 너무 춥거나 덥지 않은지 확인

💊 영양제

  • 유산균: 선택. 먹고 잘 맞으면 계속. 아토피·피부 문제가 있으면 처방 유산균도 있음
  • 비타민 D: 분유에 들어 있어서 완전 분유인 지금은 꼭 필수는 아님 (모유 수유라면 필수)

💉 접종 (헥사심 vs 따로)

  • 병원 기본은 헥사심(6가지 한 번에, B형 간염 포함). 2개월부터 맞음. 여기서도 접종 가능
  • 헥사심이 아니라 따로 맞으려면 → 1개월에 B형 간염 2차를 먼저 맞고, 2개월부터 5가 백신
  • B형 간염 기본 일정: 출생 직후 · 1개월 · 6개월

받아쓰기는 녹음에서 기계로 뽑은 거라 일부 단어가 뭉개졌습니다. 숫자·약 이름(1000ppm, 헥사심, 비판텐 등)은 문맥으로 맞췄으니, 헷갈리면 다음 검진 때 한 번 더 확인하세요. 원문: 1개월검진-받아쓰기원문-1013.txt
